
# MASTER PROMPT PEMBUATAN FLOWCHART PROFESIONAL

# DevFlow – Development Workflow Management System

## PT MAINTEK JUARA INTISOLUSI

Anda bertindak sebagai Senior System Analyst, Business Process Analyst, Solution Architect, Technical Architect, dan UI/UX Diagram Designer yang memiliki pengalaman membuat dokumentasi sistem perusahaan berskala enterprise.

Tugas Anda adalah membuat dokumentasi Flowchart profesional untuk aplikasi DevFlow – Development Workflow Management System.

Flowchart harus mengikuti standar ANSI/ISO Flowchart dan memiliki tampilan seperti dokumentasi resmi perusahaan software.

=====================================================
TUJUAN
======

Buat seluruh flowchart sistem DevFlow.

Setiap flowchart dibuat TERPISAH.

Jangan menggabungkan beberapa flowchart dalam satu halaman.

Satu flowchart = satu halaman.

Semua flowchart harus saling terhubung sebagai bagian dari sistem DevFlow.

=====================================================
DESKRIPSI SISTEM
================

DevFlow adalah aplikasi Development Workflow Management System yang digunakan oleh PT MAINTEK JUARA INTISOLUSI untuk mengelola seluruh proses Software Development Life Cycle (SDLC).

Sistem meliputi:

• Authentication
• Dashboard
• User Management
• Project Management
• Sprint Planning
• Task Management
• Internship Management
• Development Workflow
• Git Repository
• Code Review
• QA Testing
• Bug Management
• Deployment
• Maintenance
• Notification Center
• Reporting
• Client Approval

Sistem juga mengelola mahasiswa magang dari dua kampus mitra yang ikut mengerjakan project perusahaan.

=====================================================
CATATAN
=======

- Setiap flowchart dibuat secara TERPISAH.
- Jangan menggabungkan dua atau lebih flowchart dalam satu diagram.
- Setiap flowchart harus mudah dibaca pada ukuran A4 Landscape.
- Gunakan simbol ANSI/ISO yang benar.
- Semua Decision harus memiliki cabang YA dan TIDAK.
- Gunakan istilah Software Development Life Cycle (SDLC) yang profesional.
- Hasil harus siap digunakan pada Microsoft Visio, Draw.io, Lucidchart, diagrams.net, maupun dimasukkan ke laporan skripsi atau tugas akhir.
- Pastikan visual flowchart menyerupai dokumentasi profesional yang digunakan oleh perusahaan pengembang perangkat lunak.
